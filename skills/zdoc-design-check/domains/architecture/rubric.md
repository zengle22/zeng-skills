# 架构设计检查 Rubric (AD-1–AD-9)

D4 架构设计域检查项。基于 ITERATION-DOCUMENT-CHECKLIST v2.1 §2.4。

---

## AD-1 — 技术选型声明

**MAC**：语言/框架/DB/AI Provider 已确定

| 检查项 | PASS 条件 | FAIL 条件 |
|--------|----------|----------|
| 编程语言 | 已确定语言和版本 | 未确定 |
| 框架 | 已确定框架和版本 | 未确定 |
| 数据库 | 已确定数据库类型和版本 | 未确定 |
| AI Provider | 涉及 AI 时已确定 Provider | 涉及 AI 但未确定 |

---

## AD-2 — 架构分层

**MAC**：各层职责及文件位置明确

| PASS 条件 | FAIL 条件 |
|----------|----------|
| 有架构分层图或描述 | 无分层描述 |
| 每层有职责说明 | 层无职责说明 |
| 关键模块有文件位置指引 | 无文件位置指引 |
| 层间依赖关系明确 | 依赖关系不明确 |

---

## AD-3 — 同步/异步策略

**MAC**：每个外部调用标注同步/异步 + 理由

| PASS 条件 | FAIL 条件 |
|----------|----------|
| 每个外部调用有同步/异步标注 | 未标注同步/异步 |
| 同步/异步选择有理由 | 无理由说明 |
| 涉及 AI 的调用标注了超时和重试策略 | 涉及 AI 但无超时/重试 |

**Prompt 约束**：请逐项列出所有外部调用，检查同步/异步标注。输出外部调用总数和未标注数。

---

## AD-4 — 核心数据流

**MAC**：入口->出口完整链路 + 转换点 + 缓存

| PASS 条件 | FAIL 条件 |
|----------|----------|
| 有数据流图或描述 | 无数据流描述 |
| 入口到出口链路完整 | 链路有断裂 |
| 数据转换点有说明 | 转换点无说明 |
| 缓存策略有说明（如有） | 有缓存但无策略说明 |

---

## AD-5 — 粗略 API 契约

**MAC**：端点+方法+核心字段+类型+必填

| PASS 条件 | FAIL 条件 |
|----------|----------|
| 有 API 端点列表 | 无端点列表 |
| 每个端点有 HTTP 方法 | 无方法标注 |
| 核心字段有类型和必填标注 | 字段无类型/必填标注 |
| 请求/响应格式有说明 | 无格式说明 |

**Prompt 约束**：请逐项列出 API 端点，检查方法、字段类型、必填标注。输出端点总数和不完整数。

---

## AD-6 — 时序图

**MAC**：Mermaid/PlantUML，含同步/异步/超时/重试/降级/幂等

| PASS 条件 | FAIL 条件 |
|----------|----------|
| 有时序图（Mermaid/PlantUML 格式） | 无时序图 |
| 时序图包含核心业务流程 | 时序图不完整 |
| 标注了同步/异步调用 | 未标注同步/异步 |
| 标注了超时和重试策略 | 无超时/重试标注 |
| 标注了降级和幂等性（如适用） | 有降级/幂等需求但未标注 |

---

## AD-7 — 存储方案

**MAC**：关系型/文档型+关键实体+JSONB vs 规范化

| PASS 条件 | FAIL 条件 |
|----------|----------|
| 已确定数据库类型（关系型/文档型） | 未确定数据库类型 |
| 有关键实体/表设计 | 无实体设计 |
| JSONB vs 规范化有决策说明 | 无决策说明 |
| 索引策略有说明（如有） | 有索引需求但无策略 |

**注意**：如果功能不涉及持久化存储，可标记为 N/A。

---

## AD-8 — 非功能性需求

**MAC**：性能/安全/并发/降级，与时序图自洽

| PASS 条件 | FAIL 条件 |
|----------|----------|
| 有性能需求（响应时间、吞吐量） | 无性能需求 |
| 有安全需求（认证、授权、加密） | 无安全需求 |
| 有并发需求（锁策略、乐观锁） | 无并发需求 |
| 有降级策略 | 无降级策略 |
| NFR 与时序图描述自洽 | NFR 与时序图矛盾 |

---

## AD-9 — 集成点与外部依赖

**MAC**：外部服务+回调+fallback

| PASS 条件 | FAIL 条件 |
|----------|----------|
| 有外部服务清单 | 无外部服务清单 |
| 每个外部服务有调用方式说明 | 无调用方式说明 |
| 涉及回调的有回调机制说明 | 有回调但无机制说明 |
| 每个外部依赖有 fallback 方案 | 无 fallback 方案 |
