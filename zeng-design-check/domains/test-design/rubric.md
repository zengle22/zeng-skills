# 测试设计检查 Rubric (TD-1–TD-8)

D5 测试设计域检查项。基于 ITERATION-DOCUMENT-CHECKLIST v2.1 §2.5。

---

## TD-1 — AC 可测试性

**MAC**：Given-When-Then + 可测三问通过

| PASS 条件 | FAIL 条件 |
|----------|----------|
| 每条 AC 可转换为 Given-When-Then 格式 | AC 无法转换为 GWT |
| 每条 AC 回答"怎么触发"（Given） | 缺少触发条件 |
| 每条 AC 回答"怎么判定通过"（Then） | 缺少判定标准 |
| 预期结果具体可验证 | 预期结果模糊 |

---

## TD-2 — Happy Path

**MAC**：核心用户流端到端路径完整

| PASS 条件 | FAIL 条件 |
|----------|----------|
| 有核心用户流描述 | 无用户流描述 |
| 路径从入口到出口完整 | 路径有断裂 |
| 覆盖所有 P0 功能的主流程 | 有 P0 功能无主流程 |
| 每个步骤有预期结果 | 步骤无预期结果 |

---

## TD-3 — 边界条件

**MAC**：每个核心字段至少 1 个边界条件

| PASS 条件 | FAIL 条件 |
|----------|----------|
| 每个核心字段有边界条件 | 核心字段无边界条件 |
| 边界条件包含最小值/最大值 | 仅有一种边界 |
| 边界条件包含空值/特殊字符处理 | 无空值/特殊字符处理 |

**Prompt 约束**：请逐项列出核心字段，检查是否有边界条件。输出核心字段总数和无边界条件数。

---

## TD-4 — AI 不确定性场景

**MAC**：至少"AI 完全失败"+"格式异常"两种

| PASS 条件 | FAIL 条件 |
|----------|----------|
| 有 AI 完全失败场景（超时、无响应） | 无 AI 失败场景 |
| 有 AI 格式异常场景（输出不符合预期格式） | 无格式异常场景 |
| 每个场景有降级/回退方案 | 场景无降级方案 |

**注意**：如果功能不涉及 AI，可标记为 N/A。

---

## TD-5 — 测试分层策略

**MAC**：5 层覆盖（单元/集成/E2E/性能/契约）

| PASS 条件 | FAIL 条件 |
|----------|----------|
| 有单元测试策略 | 无单元测试策略 |
| 有集成测试策略 | 无集成测试策略 |
| 有 E2E 测试策略 | 无 E2E 测试策略 |
| 有性能测试策略（如适用） | 有性能需求但无测试策略 |
| 有契约测试策略（如适用） | 有外部 API 但无契约测试 |

---

## TD-6 — Mock 数据需求

**MAC**：fixture 用户 + 辅助数据 + 外部 Mock

| PASS 条件 | FAIL 条件 |
|----------|----------|
| 有 fixture 用户定义（角色、权限、数据） | 无 fixture 用户 |
| 有辅助数据定义（基础数据、配置数据） | 无辅助数据 |
| 外部服务有 Mock 方案 | 外部服务无 Mock |
| Mock 数据可复用 | Mock 数据不可复用 |

---

## TD-7 — 测试执行检查清单

**MAC**：含状态机/降级/性能三类必检项

| PASS 条件 | FAIL 条件 |
|----------|----------|
| 有状态机测试检查项（如适用） | 有状态机但无检查项 |
| 有降级测试检查项 | 无降级测试检查项 |
| 有性能测试检查项（如适用） | 有性能需求但无检查项 |
| 检查清单可执行（有具体步骤） | 检查清单不可执行 |

---

## TD-8 — TESTSET 文档

**MAC**：9 节标准结构完整

TESTSET 文档应包含以下 9 节：

| 节 | 内容 | PASS 条件 |
|----|------|----------|
| 1. 测试范围 | 本次测试覆盖的功能和排除项 | 有范围说明 |
| 2. 测试策略 | 测试分层、工具、环境 | 有策略说明 |
| 3. 测试用例 | 核心测试用例列表 | 有用例列表 |
| 4. 测试数据 | 数据准备和 Mock 方案 | 有数据说明 |
| 5. 环境需求 | 测试环境配置 | 有环境说明 |
| 6. 执行计划 | 执行顺序和依赖 | 有计划说明 |
| 7. 准入/准出标准 | 开始和结束条件 | 有标准说明 |
| 8. 风险与应对 | 测试风险和缓解措施 | 有风险说明 |
| 9. 质量指标 | 覆盖率、通过率目标 | 有指标说明 |
